# preTypeset

구글 독스 원고를 **인디자인 내지(IDML)** 의 판형·스타일로 조판한 미리보기를 문서 오른쪽에 나란히 띄우는 Chrome 확장입니다.
원고를 쓰면서 "책으로 몇 쪽이 되는지, 장이 어느 면에서 시작하는지, 코드·표가 어디서 넘어가는지"를 바로 확인하는 용도입니다.

- 브라우저 안에서만 동작합니다. 서버·브리지·InDesign 설치가 필요 없습니다.
- 조판은 **근사치**입니다. 판형·여백·단·글꼴·크기·행간·자간·들여쓰기·문단 간격은 IDML 값을 그대로 쓰지만, 줄바꿈 위치는 InDesign 컴포저와 조금 다를 수 있습니다.

## 설치

1. `chrome://extensions` → [개발자 모드] 켜기
2. [압축해제된 확장 프로그램을 로드] → 이 폴더(`preTypeset`) 선택
3. Google Docs 문서에서 툴바의 preTypeset 아이콘을 누르거나 `Alt+Shift+P`

## 사용

1. 패널 상단 [↑]를 누르거나 패널에 `.idml` 파일을 끌어다 놓습니다.
   - InDesign에서 **파일 → 다른 이름으로 저장 → 형식: InDesign Markup (IDML)** 로 저장한 파일입니다. `.indd`는 브라우저에서 읽을 수 없습니다.
   - IDML이 없으면 내장 `기본 신국판 (152×225mm)` 템플릿으로 바로 볼 수 있습니다.
2. [⚙]에서 **Docs 단락 스타일 → 내지 단락 스타일** 매핑을 확인·수정합니다. 처음에는 스타일 이름(본문, 장제목, 절제목, 코드, 각주…)으로 자동 매핑합니다.
3. 원고를 고치면 타이핑이 멈추고 약 3.5초 뒤 자동으로 다시 조판합니다. [↻]로 수동 갱신할 수 있습니다.

| 기능 | 설명 |
|---|---|
| 펼침면 / 낱쪽 | 마주보기 문서는 1쪽을 오른쪽 면에 두고 2-3, 4-5쪽을 펼침으로 보여 줍니다. |
| 확대·축소 | `−` `+`, 배율 숫자를 누르면 폭 맞춤 |
| 폭 조절 | 패널 왼쪽 가장자리를 드래그 |
| 문서 밀기 | Docs 화면을 패널 폭만큼 왼쪽으로 줄여 겹치지 않게 합니다. (설정에서 끌 수 있음) |
| 기준선 격자 | IDML 격자 설정(시작·간격)으로 겹쳐 표시 |
| 줄바꿈 | 어절 단위(`keep-all`) / 글자 단위 |
| 시작 쪽번호 | 쪽번호·홀짝 면 계산 기준 |

상태 표시줄: 총 쪽수 · 판형 · 본문 글꼴/크기/행간 · 넘침 쪽 · 이 컴퓨터에 없는 글꼴 수.
넘침(빨간 테두리)은 한 단에 다 들어가지 않는 그림·표 등 쪼갤 수 없는 블록입니다.

## IDML에서 읽는 것

- **판형**: `DocumentPreference` 폭·높이, 마주보기
- **판면**: 가장 많이 쓰인 마스터의 주 텍스트 프레임(비어 있는 큰 프레임), 없으면 마스터 페이지 여백·단 수·단 간격
- **단락 스타일**: 그룹·`BasedOn` 상속을 풀어서 글꼴·스타일(굵기), 크기, 행간(자동 행간 포함), 자간, 장평(가변 글꼴만), 첫 줄/왼쪽/오른쪽 들여쓰기, 앞/뒤 간격, 정렬(제본 쪽 정렬 포함), 색, 대문자, 단락 음영, 단락 괘선(위/아래), **단락 시작 위치**(다음 페이지·홀수 페이지·짝수 페이지·다음 단), 다음과 함께 유지, 모든 줄 함께 유지
- **마스터 요소**: 텍스트 프레임(쪽번호 `<?ACE 18?>`, 텍스트 변수), 사각형·선·타원·다각형(칠·선)
- **텍스트 변수**: "단락 스타일 일치(러닝헤드)" — 해당 스타일에 매핑된 Docs 제목이 쪽마다 반영됩니다(첫 번째/마지막). "마지막 페이지 번호"도 지원.
- **기준선 격자**: 시작 위치, 간격, 기준(페이지/여백)

## Docs에서 읽는 것

HTML 내보내기(`/export?format=html`)를 받아 블록으로 나눕니다.

- 제목(Title)·부제·제목 1~6·일반 텍스트, 글머리/번호 목록(수준별 들여쓰기), 표, 그림(Docs 본문 폭 대비 비율 유지), 페이지 나누기, 각주
- 고정폭 글꼴 문단 → `코드`, 1×1 표 → `박스`(안이 고정폭이면 `코드`)
- 굵게·기울임·밑줄·취소선·위/아래 첨자·인라인 코드 유지
- 댓글, 머리글/바닥글은 제외

## 근사 조판의 한계

- 줄바꿈·양끝 정렬은 브라우저 엔진 결과입니다. InDesign의 Adobe 컴포저·자간 조정·한국어 금칙과는 줄 단위로 차이가 날 수 있어, 쪽수는 대략 ±수% 오차를 예상하세요.
- 기준선 격자 맞춤, 고아/과부 줄 제어, 장평(일반 글꼴), 문자 스타일, 탭, 앵커 개체, GREP/중첩 스타일은 아직 반영하지 않습니다.
- 글꼴이 이 컴퓨터에 없으면 비슷한 계열(명조/고딕/고정폭)로 대체해 표시합니다. [⚙ → 내지 정보]에서 ✗ 표시된 글꼴을 확인하세요.

## 구조

```
manifest.json          MV3, Docs 문서 페이지에만 콘텐츠 스크립트 주입
background.js          툴바 아이콘/단축키 → 패널 토글 (설치 전 열린 탭은 스크립트 주입)
lib/zip.js             ZIP 리더 (DecompressionStream)
lib/idml.js            IDML → 템플릿 JSON (판형, 여백, 스타일 상속, 마스터, 변수)
lib/docs-source.js     Docs HTML export → 블록 목록
lib/style-css.js       스타일 설명자 → CSS, 굵기 추정, 글꼴 설치 확인
lib/defaults.js        내장 신국판 템플릿, 스타일 이름 자동 매핑 규칙
lib/layout.js          쪽 나눔 엔진 (단 흘리기, 줄 경계 분할, 표 행 분할, 다음과 함께 유지)
content/main.js        Shadow DOM 패널 UI, 화면 밀기, 자동 갱신, 마스터·격자 렌더링
```

템플릿은 파싱한 JSON만 `chrome.storage.local`에 저장합니다(IDML 원본은 저장하지 않음). 문서별로 마지막에 쓴 템플릿을 기억합니다.

## 테스트

```bash
node test/fixtures/build-idml.mjs   # 테스트용 IDML (마주보기 신국판, 마스터 쪽번호·러닝헤드·괘선)
node test/fixtures/build-docs.mjs   # Docs export 형식 테스트 원고
python3 -m http.server 8765         # 프로젝트 루트에서
# 브라우저로 http://127.0.0.1:8765/test/harness.html 열기
#   ?drawer=0  설정 닫기   ?page=5  5쪽으로 스크롤   ?zoom=1.6   ?spread=0   ?grid=1
#   ?big=25    원고 25배(약 300쪽) 성능 확인   ?tpl=builtin  내장 템플릿만
```
