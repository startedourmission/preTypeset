# preTypeset

구글 독스 원고를 **인디자인 내지(IDML)** 의 판형·스타일로 조판한 미리보기를 문서 오른쪽에 나란히 띄우는 Chrome 확장입니다.
원고를 쓰면서 "책으로 몇 쪽이 되는지, 장이 어느 면에서 시작하는지, 코드·표가 어디서 넘어가는지"를 바로 확인하는 용도입니다.

- 브라우저 안에서만 동작합니다. 서버·브리지·InDesign 설치가 필요 없습니다.
- 조판은 **근사치**입니다. 판형·여백·단·글꼴·크기·행간·자간·들여쓰기·문단 간격은 IDML 값을 그대로 쓰지만, 줄바꿈 위치는 InDesign 컴포저와 조금 다를 수 있습니다.

## 설치

1. `chrome://extensions` → [개발자 모드] 켜기
2. [압축해제된 확장 프로그램을 로드] → 이 폴더(`preTypeset`) 선택
3. Google Docs 문서에서 툴바의 preTypeset 아이콘을 누르거나 `Alt+Shift+P`

## 사용

1. 패널 상단 [↑]를 누르거나 패널에 `.idml` 파일을 끌어다 놓습니다.
   - InDesign에서 **파일 → 다른 이름으로 저장 → 형식: InDesign Markup (IDML)** 로 저장한 파일입니다. `.indd`는 브라우저에서 읽을 수 없습니다.
   - 패널 상단 드라이브 아이콘에 InDesign 패키지 폴더 링크를 넣어도 됩니다(아래 참고).
   - 내지를 올리기 전에는 아무것도 조판하지 않습니다.
2. [⚙]에서 **Docs 단락 스타일 → 내지 단락 스타일** 매핑을 확인·수정합니다. 처음에는 스타일 이름(본문, 장제목, 절제목, 코드, 각주…)으로 자동 매핑합니다.
3. 원고를 고치면 타이핑이 멈추고 약 3.5초 뒤 자동으로 다시 조판합니다. [↻]로 수동 갱신할 수 있습니다.

| 기능 | 설명 |
|---|---|
| 펼침면 / 낱쪽 | 마주보기 문서는 1쪽을 오른쪽 면에 두고 2-3, 4-5쪽을 펼침으로 보여 줍니다. |
| 확대·축소 | `−` `+`, 배율 숫자를 누르면 폭 맞춤 |
| 폭 조절 | 패널 왼쪽 가장자리를 드래그 |
| 문서 밀기 | Docs 화면을 패널 폭만큼 왼쪽으로 줄여 겹치지 않게 합니다. (설정에서 끌 수 있음) |
| 기준선 격자 | IDML 격자 설정(시작·간격)으로 겹쳐 표시 |
| 줄바꿈 | 어절 단위(`keep-all`) / 글자 단위 |
| 시작 쪽번호 | 쪽번호·홀짝 면 계산 기준 |

상태 표시줄: 총 쪽수 · 판형 · 본문 글꼴/크기/행간 · 넘침 쪽 · 이 컴퓨터에 없는 글꼴 수.
넘침(빨간 테두리)은 한 단에 다 들어가지 않는 그림·표 등 쪼갤 수 없는 블록입니다.

## 집필 마크업 → 디자인 요소

원고의 태그 관례(골든래빗 집필 가이드)를 읽어 조판 디자인으로 바꿉니다. [⚙ → 집필 마크업을 디자인으로]에서 끌 수 있습니다.

| 원고 | 조판 |
|---|---|
| 제목 1 `01장 제목` + `학습 목표` + `여기서 공부하는 내용` 표 | 장 도비라 펼침면 (짝수 쪽 시작) |
| 제목 2 `01.1 제목` + `난이도 하` + `학습 날짜` | 절 배너 |
| 1×2 표 `[워밍업] …` | 워밍업 박스 + 도입 문단 |
| `[1:1 코칭] 제목` … `[/1:1 코칭]` | 코칭 박스 |
| `[나]` … `[/나]`, `[AI]` … `[/AI]` | 프롬프트 / AI 말풍선 |
| `[임의]` … `[/임의]` | 일반 박스 |
| `<NOTE> 문장`, `<TIP> 문장` | 태그 박스 |
| `[바로 01] 제목`, `[바로 활용] 제목` | 실습 제목 |
| `[바로 핵심 요약]` + 목록 | 요약 박스 |
| `01단계 …` | 단계 라벨 |
| 제목 문단에 붙은 그림 | 오른쪽 글 흘리기 삽화 |

강조색은 내지 제목 스타일의 글자색에서 가져오고, [⚙ → 강조색]에서 바꿀 수 있습니다.
불러오지 못한 그림은 같은 비율의 회색 자리표시로 그려 쪽 나눔이 어긋나지 않게 합니다.

## 구글 드라이브 링크로 불러오기

패널 상단 드라이브 아이콘 → InDesign 패키지 폴더 링크를 붙여 넣고 [불러오기].

- 폴더(하위 폴더 2단계까지)에서 `.idml`을 찾아 템플릿으로 읽고, `.otf`/`.ttf`(보통 `Document fonts/`)를 받아 글꼴 저장소에 넣습니다. 이미 받아 둔 글꼴은 건너뜁니다.
- 크롬에 로그인된 구글 계정의 권한을 그대로 씁니다. 별도 API 키·OAuth 설정이 없습니다. 폴더 목록은 `drive.google.com/embeddedfolderview`(gdown과 같은 방식), 다운로드는 `drive.usercontent.google.com`을 씁니다. 비공식 경로라 구글이 바꾸면 깨질 수 있고, 그때는 직접 업로드를 쓰면 됩니다.
- 드라이브에서 불러온 템플릿은 [⚙ → 드라이브에서 다시 불러오기]로 최신 IDML을 다시 받을 수 있습니다.
- 폴더에 `.indd`만 있으면 IDML로 저장해 넣으라고 안내합니다.

## 글꼴

내지 글꼴이 이 컴퓨터에 없으면 비슷한 계열로 대체해 그리므로 줄바꿈이 달라집니다.
[⚙ → 내지 정보 → 글꼴 폴더 올리기]로 InDesign 패키지의 `Document fonts` 폴더를 올리면(끌어다 놓아도 됨) 글꼴 파일의 이름 테이블을 읽어 IDML이 부르는 이름(한글 현지화 이름, InDesign이 붙이는 `OTF`·`(OTF)` 꼬리 포함)으로 등록합니다.
글꼴은 이 브라우저의 IndexedDB(docs.google.com 저장소)에만 보관되고, 템플릿을 열 때 필요한 것만 다시 등록합니다.

## 스타일 매핑 (역할별)

마크업 컴포넌트마다 별도 매핑 키가 있고, 박스 안 위치(처음/중간/끝)에 따라 다른 IDML 스타일을 씁니다.
예: `[1:1 코칭]` 본문 → `본문_박스본문`, 마지막 문단 → `본문_박스본문E 끝`, 목록 → `본문_점S`, 마지막 항목 → `본문_점E`.
스타일 이름(그룹 접두어 제외)으로 자동 매핑하고, [⚙]에서 바꿀 수 있습니다. 매핑된 컴포넌트는 IDML의 글꼴·크기·단락 음영·들여쓰기를 그대로 쓰고, 박스 테두리·모서리 같은 모양만 미리보기가 그립니다.

## Docs와 동기화

- **커서 따라가기**: Docs 내부 텍스트 모델(Toytype과 같은 `_docs_annotate_getAnnotatedText`)로 커서 위치를 읽어, 그 문단이 있는 쪽으로 미리보기를 옮기고 파란 막대로 표시합니다.
- **미리보기 클릭 → Docs 이동**: 조판 문단을 누르면 Docs 커서가 그 문단으로 갑니다.
- **스크롤 동기화**: 양쪽 스크롤 비율을 맞춥니다. 내부 모델을 못 쓰는 환경에서도 동작합니다.
- 여러 탭 문서는 지금 보고 있는 탭(`?tab=`)만 조판합니다.

## IDML에서 읽는 것

- **판형**: `DocumentPreference` 폭·높이, 마주보기
- **판면**: 가장 많이 쓰인 마스터의 주 텍스트 프레임(비어 있는 큰 프레임), 없으면 마스터 페이지 여백·단 수·단 간격
- **단락 스타일**: 그룹·`BasedOn` 상속을 풀어서 글꼴·스타일(굵기), 크기, 행간(자동 행간 포함), 자간, 장평(가변 글꼴만), 첫 줄/왼쪽/오른쪽 들여쓰기, 앞/뒤 간격, 정렬(제본 쪽 정렬 포함), 색, 대문자, 단락 음영, 단락 괘선(위/아래), **단락 시작 위치**(다음 페이지·홀수 페이지·짝수 페이지·다음 단), 다음과 함께 유지, 모든 줄 함께 유지
- **마스터 요소**: 텍스트 프레임(쪽번호 `<?ACE 18?>`, 텍스트 변수), 사각형·선·타원·다각형(칠·선)
- **텍스트 변수**: "단락 스타일 일치(러닝헤드)" — 해당 스타일에 매핑된 Docs 제목이 쪽마다 반영됩니다(첫 번째/마지막). "마지막 페이지 번호"도 지원.
- **기준선 격자**: 시작 위치, 간격, 기준(페이지/여백)

## Docs에서 읽는 것

HTML 내보내기(`/export?format=html`)를 받아 블록으로 나눕니다.

- 제목(Title)·부제·제목 1~6·일반 텍스트, 글머리/번호 목록(수준별 들여쓰기), 표, 그림(Docs 본문 폭 대비 비율 유지), 페이지 나누기, 각주
- 고정폭 글꼴 문단 → `코드`, 1×1 표 → `박스`(안이 고정폭이면 `코드`)
- 굵게·기울임·밑줄·취소선·위/아래 첨자·인라인 코드 유지
- 댓글, 머리글/바닥글은 제외

## 근사 조판의 한계

- 줄바꿈·양끝 정렬은 브라우저 엔진 결과입니다. InDesign의 Adobe 컴포저·자간 조정·한국어 금칙과는 줄 단위로 차이가 날 수 있어, 쪽수는 대략 ±수% 오차를 예상하세요.
- 기준선 격자 맞춤, 고아/과부 줄 제어, 장평(일반 글꼴), 문자 스타일, 탭, 앵커 개체, GREP/중첩 스타일은 아직 반영하지 않습니다.
- 글꼴이 이 컴퓨터에 없으면 비슷한 계열(명조/고딕/고정폭)로 대체해 표시합니다. [⚙ → 내지 정보]에서 ✗ 표시된 글꼴을 확인하세요.

## 구조

```
manifest.json          MV3, Docs 문서 페이지에만 콘텐츠 스크립트 주입
background.js          툴바 아이콘/단축키 → 패널 토글 (설치 전 열린 탭은 스크립트 주입)
lib/zip.js             ZIP 리더 (DecompressionStream)
lib/idml.js            IDML → 템플릿 JSON (판형, 여백, 스타일 상속, 마스터, 변수)
lib/docs-source.js     Docs HTML export → 블록 목록
lib/style-css.js       스타일 설명자 → CSS, 굵기 추정, 글꼴 설치 확인
lib/defaults.js        내장 신국판 템플릿, 스타일 이름 자동 매핑 규칙
lib/layout.js          쪽 나눔 엔진 (단 흘리기, 줄 경계 분할, 표 행 분할, 다음과 함께 유지)
lib/markup.js          집필 마크업 → 디자인 컴포넌트
content/main.js        Shadow DOM 패널 UI, 화면 밀기, 자동 갱신, 마스터·격자·컴포넌트 렌더링, 동기화
content/page-bridge.js 메인 월드 브리지 (Docs 텍스트 모델·커서)
lib/drive-bg.js        (백그라운드) 드라이브 폴더 목록·파일 다운로드, 1MB씩 패널로 전달
lib/fonts.js           글꼴 파일 이름 테이블 읽기, IndexedDB 보관, FontFace 등록
```

템플릿은 파싱한 JSON만 `chrome.storage.local`에 저장합니다(IDML 원본은 저장하지 않음). 문서별로 마지막에 쓴 템플릿을 기억합니다.

## 실제 책과 비교 (바로바로 클로드 1장)

같은 원고(Docs)와 같은 IDML·글꼴로 조판한 미리보기의 절·실습 시작 쪽을 인쇄본 목차와 비교한 결과:

| 항목 | 인쇄본 | 미리보기 |
|---|---|---|
| 01.1 / 01.2 / 01.3 / 01.4 | 020 / 026 / 037 / 051 | 20 / 26 / 37 / 51 |
| 바로 01 · 02 · 04 · 07 | 026 · 031 · 037 · 059 | 같음 |
| 바로 03 · 05 · 06 | 034 · 045 · 057 | 35 · 44 · 58 |

절 단위로는 일치하고, 절 안에서는 ±1쪽 차이가 납니다(삽화 크기·배너 높이·수동 조정 차이).

## 테스트

```bash
node test/fixtures/build-idml.mjs   # 테스트용 IDML (마주보기 신국판, 마스터 쪽번호·러닝헤드·괘선)
node test/fixtures/build-docs.mjs   # Docs export 형식 테스트 원고
python3 -m http.server 8765         # 프로젝트 루트에서
# 브라우저로 http://127.0.0.1:8765/test/harness.html 열기
#   ?drawer=0  설정 닫기   ?page=5  5쪽으로 스크롤   ?zoom=1.6   ?spread=0   ?grid=1
#   ?big=25    원고 25배(약 300쪽) 성능 확인   ?tpl=builtin  내장 템플릿만
#   ?src=private/doc.html   실제 원고 export (test/fixtures/private/, 커밋 안 됨)
#   ?synctest=찾을문장       가짜 Docs 모델로 커서 따라가기 확인
#   ?idml=private/x.idml&fonts=1&start=18   실제 IDML·글꼴(private/fonts/)로 조판

# 비동기 작업(IndexedDB·글꼴)까지 기다려 결과와 스크린샷을 받는 실행기 (Chrome DevTools 프로토콜)
node test/run-harness.mjs "src=private/doc.html&idml=private/x.idml&fonts=1&start=18" --shot out.png --pages 20,26
```
